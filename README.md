# three-body

## 三体悬浮雕塑（`index.html`）

复原《三体》第一部地球三体组织（ETO）聚会上的磁悬浮三体雕塑：三颗金属球悬浮在线圈底座上方，互相牵引，做永不重复的混沌运动。基于 three.js 的三维实时场景。

**打开方式**：用浏览器直接打开 `index.html`（需联网，从 jsDelivr 加载 three.js）。

### 功能
- **多角度查看**：拖动旋转、滚轮缩放、右键平移；预设斜视 / 平视 / 俯视 / 仰视，可开关自动环绕
- **三种运动模式**
  - 乱纪元：随机初始条件 + 底座磁场约束，真正的混沌运动（会自动筛选对初值敏感的种子）
  - 恒纪元：8 字形周期解（Moore 1993；Chenciner & Montgomery 2000）
  - 三角：拉格朗日等边三角形解，不稳定，几圈后崩溃，转入乱纪元
- 轨迹、磁力线、标注开关；时间流速 0.1–3×
- 实时读数：纪元、文明序号、三体时、最近球距（cm）、能量守恒误差、事件（相撞反弹 / 三日连珠 / 恒纪元崩溃）
- 快捷键：`空格` 暂停，`R` 重启，`1`–`4` 视角，`T` 轨迹

### 物理模型
- 等质量牛顿引力，速度 Verlet 积分，近距离时自动细分步长
- 乱纪元模式额外加入：底座的各向异性谐振磁阱、同极磁化的 B/r² 近距排斥、陡峭接触核（防止穿模）。全部为保守力，所以能量误差可以作为精度指标
- 比例：1 场景单位 = 40 cm，底座直径约 1.8 m，金属球直径约 19 cm
